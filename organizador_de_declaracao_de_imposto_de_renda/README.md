# 📊 Organizador de Informações para Imposto de Renda — Excel

## 📌 Sobre o Projeto

Ferramenta desenvolvida no Microsoft Excel para centralizar e organizar informações necessárias à declaração do Imposto de Renda, utilizando menus de navegação, validação de dados e links rápidos.

## 🎯 Objetivos

- Aplicar conhecimentos de Excel na prática;
- Organizar e validar informações;
- Desenvolver documentação técnica;
- Utilizar o GitHub para compartilhar projetos.

## ⚙️ Funcionalidades

- Centralização de informações;
- Menus de navegação;
- Validação de dados;
- Links de acesso rápido;
- Interface intuitiva.

## 🛠️ Tecnologias

- Microsoft Excel
- Git e GitHub

## 📈 Resultados

Aplicação prática dos recursos do Excel para criar uma ferramenta organizada, funcional e fácil de utilizar.

## ⚠️ Observação

Projeto de finalidade educacional e organizacional. Não substitui as orientações oficiais da Receita Federal ou de um profissional contábil.

## 👨‍🏫 Créditos

Desafio prático da **DIO (Digital Innovation One)**, com orientação de **Felipão**.
