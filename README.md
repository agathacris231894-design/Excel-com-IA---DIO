# 📊 Bootcamp DIO — Santander - Excel com IA e Claude

## 📌 Sobre o bootcamp

Bootcamp da [Digital Innovation One (DIO)](https://www.dio.me/) com apoio da empresa Santander voltado ao aprendizado de Microsoft Excel, desde os conceitos fundamentais até a aplicação de fórmulas, tratamento e visualização de dados em relatórios, com apoio de ferramentas de Inteligência Artificial.

A formação combina conteúdos teóricos, exercícios práticos e desafios de projeto para desenvolver habilidades aplicáveis a problemas reais do mercado de trabalho.

## 🎯 Objetivos

- Aprender os fundamentos do Microsoft Excel.
- Compreender e aplicar as principais fórmulas e funções.
- Organizar, tratar e analisar dados.
- Criar relatórios eficientes para apoiar a tomada de decisões.
- Utilizar recursos de Inteligência Artificial como apoio à produtividade.
- Aplicar os conhecimentos adquiridos em projetos práticos.

## 🛠️ Ferramentas e tecnologias

- **Microsoft Excel:** organização, tratamento e análise de dados.
- **Fórmulas e funções:** automatização de cálculos e consultas.
- **Visualização de dados:** apresentação de informações em relatórios.
- **Inteligência Artificial:** apoio à produtividade e à resolução de problemas.

## 📚 Metodologia de aprendizagem

A jornada é composta por cursos com aulas objetivas, avaliações de conhecimento e desafios de projeto que permitem aplicar os conteúdos estudados em situações práticas.

A plataforma também oferece recursos para acompanhar o progresso, estabelecer metas de estudo, interagir com outros participantes e compartilhar conhecimentos por meio do fórum e de espaços colaborativos.

## 🚀 Projeto prático

### Simulador de Investimentos em Fundos Imobiliários (FIIs)

Como aplicação prática dos conhecimentos adquiridos, desenvolvi um simulador de investimentos em Fundos Imobiliários utilizando o Microsoft Excel.

O projeto permite estimar o patrimônio acumulado e os dividendos mensais a partir de aportes periódicos, além de comparar cenários de investimento e distribuir os aportes conforme diferentes perfis de investidor.

Entre os recursos utilizados estão:

- Função `VF` para calcular o valor futuro dos investimentos.
- Função `PROCV` para consultar percentuais de alocação.
- Intervalos nomeados para facilitar a leitura das fórmulas.
- Validação de dados para seleção do perfil de investidor.
- Tabelas auxiliares e chave composta para automatizar a distribuição dos aportes.
